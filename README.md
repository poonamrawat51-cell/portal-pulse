# Portal Pulse — Automated HubSpot Portal Health Auditor 🚀

**Live Demo:** [https://portal-pulse-khaki.vercel.app](https://portal-pulse-khaki.vercel.app)

Portal Pulse is a RevOps diagnostic engine designed to scan HubSpot workflow logic, lead routing rules, and property configurations. It detects misconfigurations, broken assignment logic, and property bloat before they lead to lost revenue and unassigned leads.

---

## Key Features

- **Automated Workflow Diagnostics:** Grades workflow text and property JSON across 4 core dimensions:
  - Workflow Efficiency
  - Lead Routing & Assignment Logic
  - Pipeline & Lifecycle Hygiene
  - Data Quality & Property Management
- **Instant Health Scoring:** Generates an overall Executive Health Index (0–100) alongside priority bottleneck summaries.
- **Interactive UI:** Built with dark-mode React components, active section navigation, pricing tiers, and booking modals.
